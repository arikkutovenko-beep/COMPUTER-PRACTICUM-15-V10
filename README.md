## Звіт з безпеки (Практична робота №15)

### 1. Аудит та усунення XSS-вразливостей
* **Виявлена вразливість:** До виправлення поля `trip.destination`, `stop.name`, `stop.description` вставлялися в `appContainer.innerHTML` без попередньої обробки в функції `renderTripDetails` та `renderStopDetails`.
* **Вектор атаки:** Введення рядка `<img src=x onerror="alert('XSS')">` у форму додавання поїздки призводило до виконання довільного JavaScript-коду.
* **Виправлення:** Впроваджено функцію `escapeHtml()` у `script.js`, яка перетворює спецсимволи (`<`, `>`, `&`, `"`, `'`) на відповідні HTML-сутності (`&lt;`, `&gt;` тощо) перед формуванням HTML-рядка. Усі дані з локального Express API та форм тепер безпечно відображаються як звичайний текст.

### 2. Аудит клієнтських сховищ (localStorage та IndexedDB)
* Перевірено вміст сховищ `legacy_trip_stops` та `TravelPlannerDB`.
* Висновок: у сховищі зберігаються лише описи поїздок, дати та бюджет. Чутлива інформація (паролі, приватні токени авторизації, персональні документи) відсутня, що відповідає вимогам безпеки клієнтських застосунків.

### 3. HTTPS та секрети
* Застосунок не містить захардкоджених секретних ключів чи паролів.
* Застосунок підготовлено для розгортання на GitHub Pages / Vercel із задіяним HTTPS-протоколом.
